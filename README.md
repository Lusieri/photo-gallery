# 📷 개인 온라인 사진 전시회 (Online Photo Exhibition)

> **"기억의 틈, 빛의 결"** - 개인 사진 아카이브 및 전시용 포트폴리오 웹사이트

실제 사진전 미술관에 온 것처럼 개인의 사진을 우아하고 몰입감 있게 전시하고 감상할 수 있는 맞춤형 웹사이트입니다.

---

## 🌟 주요 기능 및 특징

1. **두 가지 전시관 관람 모드**:
   - **그리드 뷰 (Masonry Grid)**: 사진 본연의 비율(가로/세로/정방형)을 살려 유려하게 배치되는 갤러리 뷰.
   - **전시장 워크스루 (Museum Walkthrough)**: 미술관 벽면에 액자가 걸려있는 듯한 가상 전시장 복도를 좌우로 거닐며 감상하는 수평 스크롤 모드 (마우스 휠 지원).

2. **심도 깊은 작품 상세 모달 (라이트박스)**:
   - 고화질 전체 화면 감상 & 클릭 시 확대/축소(Zoom) 기능
   - 작가의 시선이 담긴 사진 속 이야기(에세이/캡션)
   - 카메라 바디, 렌즈, 조리개(Aperture), 셔터스피드, ISO 등 **EXIF 촬영 제원** 표시
   - 키보드 방향키(`←`, `→`) 및 `ESC` 단축키 지원
   - 관람객 응원 하트(좋아요) 및 링크 공유 기능

3. **갤러리 분위기 연출**:
   - **다크 룸 (Dark Room)** & **화이트 큐브 (White Cube)** 테마 실시간 토글 (선호 테마 자동 저장)
   - **생성형 앰비언트 사운드 (BGM)**: 외부 음원 파일 없이도 브라우저에서 잔잔하고 명상적인 전시장 배경음을 생성하는 토글 버튼 제공

4. **소통과 기록**:
   - 작가 프로필 & 아티스트 스테이트먼트
   - 감성 스탬프와 함께 한 줄 평을 남길 수 있는 **관람객 방명록**

5. **손쉬운 사진 등록 및 관리 (큐레이터 스튜디오)**:
   - 코딩 없이도 웹 브라우저(`admin.html`)에서 내 컴퓨터의 사진을 드래그하여 등록하고, 버튼 하나로 설정을 저장/내보낼 수 있습니다.

## 🎨 내 사진으로 교체하고 추가하는 방법

### 방법 1. [가장 추천] 큐레이터 스튜디오(`admin.html`) 활용하기
1. 웹 브라우저에서 `admin.html`을 엽니다 (메인 페이지 우측 상단 `+ 사진 관리` 클릭).
2. 전시회 제목, 작가 소개, 인스타그램 등을 원하는 문구로 수정합니다.
3. 전시하고 싶은 사진 파일을 `assets/images/` 폴더에 복사해 넣은 뒤, 폼에 제목과 촬영 정보(EXIF)를 입력하고 **[+ 전시에 작품 추가하기]**를 누릅니다.
4. 하단의 **[data.js 다운로드]** 버튼을 눌러 `js/data.js` 파일에 덮어쓰면 끝!

### 방법 2. `js/data.js` 파일 직접 수정하기
- 메모장이나 VS Code 등 편집기로 `js/data.js` 파일을 열어 `photos` 배열에 사진 경로(`src`), 제목(`title`), 설명(`description`)을 직접 편집할 수도 있습니다.

## 🌐 무료 웹 배포 방법 (친구들에게 링크로 보여주기)
